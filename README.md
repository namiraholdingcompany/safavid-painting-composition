## چکیده

نگارگری صفوی به عنوان یکی از دوران طلایی هنر ایران شناخته می‌شود که با ترکیب‌بندی‌های نوآورانه و پیچیده خود متمایز گردیده است. این پژوهش کیفی، با روش توصیفی-تحلیلی، به بررسی نقش ترکیب‌بندی به عنوان یک زبان بصری در نگارگری صفوی می‌پردازد.
